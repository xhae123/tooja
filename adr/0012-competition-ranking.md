# ADR 0012: 공동 순위는 1·1·3 방식으로 표시한다

기록일: 2026-10-05 · 결정 출처: 사용자 결정

## 배경

같은 투자금을 받은 두 팀의 순위를 1·1 또는 2·2 등 어떻게 표시할지 결정이 필요했습니다. PDF의 임시안과 대화에서 확정한 방식이 달랐습니다.

## 결정

유치금 내림차순 경쟁 순위(1,1,3)를 사용합니다. 동률 팀의 표시 순서는 팀 번호 오름차순입니다.

## 선택 이유

사용자가 경쟁 순위 방식을 선택했습니다. 같은 금액은 같은 순위로 보이고 다음 순위는 해당 위치만큼 건너뜁니다.

## 비교한 대안

공동 순위 없는 1~20 표시와 밀집 순위 1,1,2는 채택하지 않았습니다.

## 영향과 한계

프론트엔드는 배열 인덱스 대신 서버 rank를 표시해야 합니다. 모두 0원이면 20개 팀이 모두 1위이며 표시 순서만 팀 번호순입니다.
