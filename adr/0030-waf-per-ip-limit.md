# ADR 0030: WAF는 IP별로 여유 있게 요청을 제한해요

## 배경

기존 nginx의 전체 합산 500r/s를 OCI WAF로 그대로 옮길 수 없어요. 사용자는 극단적인 공격만 막도록 IP별 제한을 높게 두는 변경을 허용했어요.

## 결정과 이유

IP당 60초 동안 30,000건을 초과하면 60초 제한해요. 평균 500건/초에 해당하지만 순간 500r/s나 전역 합산 500r/s와 같지는 않아요. 행사장 공용 IP를 고려한 느슨한 기준이에요.

429에는 Retry-After: 60을 제공해요. 클라이언트가 임의 설정한 X-Forwarded-For를 제한 키로 쓰지 않아요. 기존 앱의 역할·계정별 제한은 유지해요.

## 한계

한국 IP의 코드 추측이나 분산 공격을 완전히 막는 설정은 아니에요. 처리 용량과 무료 사용량 보장도 아니에요.

[기존 전역 제한](0023-nginx-country-and-service-rate-limit.md)을 대체해요.
