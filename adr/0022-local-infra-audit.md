# ADR 0022: 직접 인프라·DB 작업은 .local에 기록한다

기록일: 2026-10-05 · 결정 출처: 사용자 결정

## 배경

CI 밖에서 최초 서버 설정과 DB 직접 조작을 수행합니다. 어떤 작업을 했는지, 결과와 복구 범위가 무엇인지 사용자가 검토할 수 있어야 합니다.

## 결정

인프라 작업은 .local/infra, DB SQL·스크립트·건수·검증은 .local/db에 기록합니다. 가상 명단과 더미 코드는 .local/dummy-data.yaml로 제공합니다.

## 선택 이유

CI 로그와 별개로 직접 수행한 작업의 목적·전후 상태·검증을 남깁니다. 실제 비밀값과 사용자 데이터는 작업 로그에 남기지 않으며 .local 전체를 Git·Docker·CI artifact에서 제외합니다.

## 비교한 대안

공개 저장소에 DB 스냅샷·환경 파일·키 원문을 넣는 방식은 사용하지 않습니다. 이력 없이 DB를 즉흥 수정하지 않습니다.

## 영향과 한계

로컬 기록은 자동으로 원격 공유·백업되지 않습니다. 가상 명단은 실제 명단이 아니며 실제 발급 코드를 일반 로그로 남겨서는 안 됩니다. 직접 DB 변경 전후에는 트랜잭션·백업 API·무결성·관련 API 검증을 수행합니다.

## 현재 상태와 구현 근거

AGENTS.md와 .gitignore에 반영됨. 현재 최초 설정·삭제·배포·더미 삽입·검증 기록이 있습니다.
