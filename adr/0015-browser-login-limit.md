# ADR 0015: 로그인 횟수는 브라우저에서 제한한다

기록일: 2026-10-05 · 결정 출처: 사용자 결정

## 배경

약 140명이 행사장 공용 Wi-Fi를 쓰면 IP 하나로 정상 로그인 시도가 몰립니다. IP당 작은 로그인 제한은 정상 사용자를 함께 막을 수 있습니다.

## 결정

투자자·관리자 로그인은 localStorage 기반 브라우저 제한을 사용합니다. 다른 보호 API는 역할·계정별, 공개 대시보드는 IP별 서버 제한을 사용합니다.

## 선택 이유

공용 IP를 로그인 제한 단위로 삼지 않겠다는 사용자 선택을 따랐습니다. 투자자 60초 10회·관리자 5회는 현재 화면 구현값입니다.

## 비교한 대안

로그인 IP당 분당 10회 제안은 공용 Wi-Fi 문제로 채택하지 않았습니다.

## 영향과 한계

localStorage는 삭제·우회할 수 있어 공격자에 대한 서버 인증 방어가 아닙니다. 해외 접속 차단은 사용자 계획이며 이번 CI/CD에서 구현·검증한 기능이 아닙니다. 서버 제한 카운터는 JVM에 있어 재시작하면 초기화됩니다.

## 현재 상태와 구현 근거

브라우저 제한과 일반 API 서버 제한은 구현됨. 해외 차단은 미구현입니다.
