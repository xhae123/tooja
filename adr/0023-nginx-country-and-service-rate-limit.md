# 0023. tooja에만 한국 IP 허용과 서비스 전체 요청 제한을 적용한다

- 결정일: 2026-10-05
- 상태: 채택
- 결정 근거: 사용자가 해외 차단 즉시 적용과 전체 초당 500건을 지정했다.

## 배경

행사장 Wi-Fi에서는 약 140명이 같은 공인 IP를 사용할 수 있다. 낮은 IP별 로그인 제한은 정상 참가자의 동시 접속을 막을 수 있다. 사용자는 엄격한 차단보다 극단적인 요청 폭주를 완화하기를 원했다.

## 결정

tooja server 블록에서 한국 IP만 허용한다. 국가 데이터는 무료 DB-IP Lite에서 한국 범위를 추출해 nginx 기본 geo 모듈로 조회한다. 모든 API는 서비스 전체 합산 초당 500건, 순간 초과 여유 1000건을 공유한다. 별도 nginx 로그인 제한은 두지 않는다.

## 선택 이유와 대안

추가 GeoIP2 모듈과 국가 MMDB를 사용할 수도 있지만 기존 nginx 이미지의 교체·확장 없이 CIDR 조회로 같은 목적을 구현할 수 있다. 유료 WAF 도입은 이번 범위와 비용 정책에 포함하지 않는다. IP별 낮은 한도는 행사장 공용 IP를 제한하므로 선택하지 않았다.

## 결과와 한계

해외 GitHub Actions 러너의 HTTP 점검도 차단된다. SSH로 인증된 서버에서 loopback으로 nginx를 거쳐 검증하고, 배포 커밋을 확인한 증거를 Actions에 반환한다. 서버 내부 점검 주소만 허용하고 해외 러너 IP는 허용하지 않는다.

국가 데이터는 매월 갱신하고 한국 범위가 바뀔 때만 nginx를 reload한다. 앱 CI/CD에서는 여전히 nginx를 변경하지 않는다. 국가 오분류와 한국 VPN 우회는 가능하다. 요청 제한은 네 자리 코드 추측이나 대규모 네트워크 DDoS의 완전한 방어가 아니며, 500건은 서버의 지속 처리 능력을 검증한 수치가 아니다.
