# ADR 0005: 두 역할 모두 재사용하는 숫자 4자리 코드로 로그인한다

기록일: 2026-10-05 · 결정 출처: 사용자 결정

## 배경

처음에는 관리자 아이디·비밀번호와 단어 조합 코드를 논의했지만, 요구사항 재확인 후 관리자도 코드 인증으로 변경했습니다. 코드는 일회용이 아니라 식별키입니다.

## 결정

투자자·관리자 모두 ASCII 숫자 4자리 문자열을 발급합니다. 앞자리 0을 유지하고 역할이 맞는 활성 계정에 대해서만 로그인합니다. 원문 대신 pepper를 포함한 해시를 DB에 저장합니다.

## 선택 이유

현장에서 짧은 코드를 배부·입력하기 쉽다는 사용자 선택을 따랐습니다. 사전 발급 때 코드 중복을 막아 계정을 식별합니다.

## 비교한 대안

긴 무작위 코드, 아이디·비밀번호, 일회용 코드는 검토했지만 이번 사용자 결정과 달라 채택하지 않았습니다.

## 영향과 한계

가능한 코드 수는 10,000개로 추측에 강한 형식은 아닙니다. 브라우저 제한을 서버 방어로 간주하지 않습니다. 실제 코드 배부·분실 대응은 사용자가 담당하며 CODE_PEPPER를 임의 변경하면 기존 로그인 코드 해시가 맞지 않습니다.
