# ADR 0013: 투자 시작·마감 기능 없이 현재 현황을 제공한다

기록일: 2026-10-05 · 결정 출처: 사용자 결정

## 배경

관리자는 현재 순위와 미소진자·미지급자를 볼 수 있습니다. 앱이 정확한 시각에 투자를 멈추고 최종 결과를 확정해야 하는지는 별도 결정이었습니다.

## 결정

서버의 투자 시작·마감·결과 동결·자동 감점을 제공하지 않습니다. 관리자가 조회 화면을 필요한 시점에 캡처하고 심사 처리를 진행합니다.

## 선택 이유

사용자는 화면 캡처와 외부 운영으로 처리할 수 있다고 판단했습니다. 앱의 책임 범위를 현재 데이터 제공으로 정했습니다.

## 비교한 대안

마감 상태로 모든 투자를 막거나 특정 시점의 순위를 서버에 영구 보관하는 방식은 이번 범위에서 제외했습니다.

## 영향과 한계

asOf는 조회 시각이지 마감 확정 시각이 아닙니다. 캡처 이후 투자로 순위가 달라질 수 있으며 정식 결과 동결 요구가 생기면 별도 기능이 필요합니다.

## 현재 상태와 구현 근거

구현됨. 미지급자와 지급 후 미소진자는 관리자 목록 필터로 각각 조회합니다.
