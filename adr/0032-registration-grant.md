# ADR 0032: 등록 시 100만원을 지급하고 소진 상태를 두 가지로 줄인다

기록일: 2026-10-14 · 결정 출처: 사용자 결정 · ADR 0007 대체

## 배경

이전에는 최초 로그인할 때 지급했습니다. 지급과 로그인 여부를 함께 관리하면서 미로그인·미지급, 미소진, 완료 세 상태가 필요했습니다. 완성된 Figma에는 미로그인자 조회가 없고, 사용자가 등록 시 지급과 상태 간소화를 요청했습니다.

## 결정

참가자와 운영팀 투자자는 사전 등록 시 100만원을 지급받습니다. 계정·잔액·지급 원장을 한 트랜잭션에서 생성하며 재등록과 재로그인은 기존 잔액을 덮어쓰지 않습니다. 관리자는 지급 대상이 아닙니다.

소진 상태는 UNSPENT와 COMPLETED만 사용합니다. hasLoggedIn·activatedInvestorCount·notActivatedCount와 NOT_ACTIVATED 필터를 제거합니다. 모든 등록 투자자를 지급액·잔액·미소진 집계에 포함합니다.

## 기존 DB와 배포

사용자가 기존 DB를 이전 가상 명단으로 초기화하도록 승인했습니다. Actions 배포 검증 이후 보호된 일관 백업을 만들고 업무 데이터만 초기화합니다. Flyway V2는 활성화 열을 제거하며 배포 전환 중 기존 미지급 등록자도 지급 상태로 정리합니다. 이미 지급된 잔액·거래는 마이그레이션에서 보존합니다. 적용된 V1 파일은 수정하지 않습니다.

## 검증

SQLite·MySQL에 동일 API 계약 테스트를 실행합니다. 등록 시 지급, 관리자 제외, 등록 중 실패 롤백, 재등록·재로그인·동시 로그인 시 재지급 방지, 상태 필터·현황 집계와 이전 MySQL 스키마 전환을 검증합니다. CI는 단위·통합만 실행합니다.
