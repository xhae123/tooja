# ADR 0033: 투자자 이름 수정 기능을 제거한다

기록일: 2026-10-21 · 결정 출처: 사용자 요청

## 배경

초기에는 발급 시 만든 별칭을 관리자가 알아보기 쉬운 이름으로 바꿀 수 있게 했습니다. 실제 행사 전에는 명단을 다시 준비해 정확한 이름을 DB에 직접 등록할 계획이므로, 관리자 화면에서 이름을 수정할 필요가 없어졌습니다.

## 결정

관리자 이름 수정 API와 입력 DTO·서비스·화면의 입력창·저장 동작을 제거합니다. 투자자 목록·상세의 이름 조회와 검색은 유지합니다. 기존 `alias` 응답 필드와 DB 열은 사전 등록 이름을 담는 용도로 유지해 불필요한 필드명 변경이나 데이터 이전을 하지 않습니다.

## 외부 동작

`/api/v1/admin/investors/{investorId}`는 GET만 지원합니다. 기존 PATCH 요청에는 405 METHOD_NOT_ALLOWED를 반환합니다. Swagger에서 수정 작업과 AliasInput 스키마를 제거합니다. 전체 API 작업 수는 22개에서 21개가 됩니다.

## 검증과 운영 범위

SQLite·MySQL에서 수정 요청 거절, 이름·잔액·지급 기록 유지, 기존 상세 조회와 이름 검색을 검증합니다. 브라우저에서는 등록 이름 표시와 수정 UI 제거를 확인합니다. 기존 DB를 초기화하거나 이름을 직접 바꾸지 않으며, 행사 전 실제 명단 등록은 별도 작업입니다.
